# 📋 Plan de Pruebas

## 1. Alcance
Este documento define la estrategia de pruebas para la plataforma **SenaWork**.

## 2. Tipos de Pruebas Ejecutadas
- **Pruebas Funcionales (Manual):** Módulos de autenticación, publicación de vacantes y postulaciones.
- **Database Testing:** Verificación de integridad referencial y persitencia mediante consultas SQL en MySQL.

## 3. Entorno de Pruebas
- **DB:** MySQL 8.0 (vía Xampp)
- **Backend:** Laravel 11 / PHP 8.2
- **Herramientas QA:** MySQL Workbench / DBeaver
